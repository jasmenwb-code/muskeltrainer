# Anatomy Duel

Lern-App für 84 Muskeln (Ursprung, Ansatz, Funktion, Innervation) mit Abbildungen, Vorlesen, Spracheingabe und Live-Duell gegen Freunde.

- Website: https://anatomyduel.com/
- Lernen funktioniert ohne Konto und offline (zum Startbildschirm hinzufügen).
- Duelle laufen über Firebase (Anmeldung mit E-Mail und Passwort, Realtime Database). Die Datenbank-Regeln stehen in `database.rules.json`.
